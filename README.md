# 我的第一张待办清单

这是一个适合初学者的中文练习项目。可以添加任务、勾选完成、删除任务，以及清除已完成的任务。

## 先运行一次

在电脑上双击 `index.html`（网页入口文件），用浏览器打开。无需安装额外工具。

添加一项任务，勾选完成，再刷新页面。任务记录保存在当前浏览器中；不同浏览器、不同电脑，以及文件和网页地址之间的记录不自动同步。

## 三个文件分别做什么

- `index.html`（网页入口文件）：包含页面、外观和交互代码。
- `README.md`（项目说明文件）：介绍这个项目以及如何使用。
- `AGENTS.md`（编程助手工作规则文件）：告诉编程助手修改这个项目时要遵守什么。

## 上传到自己的仓库

1. 打开自己的 GitHub（代码托管平台）仓库。
2. 空仓库页面点击 `uploading an existing file`（上传现有文件）；已有文件时选择 `Add file`（添加文件）中的 `Upload files`（上传文件）。
3. 将以上三个文件拖入上传区域。三个文件应直接位于仓库根目录。
4. 提交说明填写“添加待办清单第一版”，点击 `Commit changes`（提交更改），完成第一次提交。
5. 检查仓库的 `main`（主分支）中已经出现这三个文件。

在仓库里点击网页文件通常会显示源代码；这是保存项目，尚未把网页发布成公开网站。

## 怎样继续和编程助手配合

第一次修改可以直接说：

> 请读取我的仓库。这个项目是中文待办清单，请把页面改成绿色主题。请在新分支中修改，检查功能，告诉我改了什么，暂时不要合并。

也可以逐步增加截止日期、任务分类或主题切换，一次只做一个功能。

## 云端设置时可以这样说明

> 这是一个独立静态网页项目，入口是 index.html（网页入口文件），不需要安装依赖，也不需要账号密钥。请按这种项目完成云端环境设置，记录可完成的检查；若不能运行浏览器检查，请如实说明。

这个项目不需要额外安装软件包。不需要为了完成环境设置而新增构建工具。

## 简单验收

- 添加“今天学习一次上传”，清单数量应变为一项。
- 勾选任务，已完成数量应变为一项。
- 刷新后，任务与完成状态应保留。
- 点击“清除已完成”，清单应恢复为空。
- 添加两项，删除其中一项，另一项应保留。
